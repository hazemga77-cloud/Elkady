# Stock Hunter — prototype

## تشغيل محلي
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل المجلد.
3. نفّذ:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. سيفتح الموقع محليًا في المتصفح.

## ما الذي تفعله النسخة؟
- تفحص قائمة أولية من الأسهم الأمريكية.
- تستبعد الأسهم التي يزيد سعرها عن الحد المحدد.
- تعرض ترتيبًا منفصلًا للاستثمار الطويل والصفقات القصيرة.
- تجمع مؤشرات مالية وفنية متاحة من Yahoo Finance عبر yfinance.
- تصدّر النتائج إلى CSV.

## مهم قبل النشر والاستخدام الفعلي
- هذه نسخة أولية وليست نظامًا استثماريًا إنتاجيًا.
- مزود البيانات قد يغيّر الوصول أو يقيّد الطلبات، وقد تكون البيانات متأخرة/ناقصة.
- لا توجد بعد مصادقة شرعية أو تنبيهات مجدولة أو قاعدة بيانات تاريخية للترشيحات.
- للحصول على تشغيل يومي تلقائي: انشر التطبيق على استضافة تدعم Streamlit، وأضف مهمة مجدولة/خدمة خارجية لتشغيل الفحص وحفظ النتائج. لا تضع مفاتيح API داخل الكود.
- اختبر التقييم على بيانات تاريخية (backtesting) قبل استخدامه بأموال حقيقية.
